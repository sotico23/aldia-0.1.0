  - config/services.php
  - app/Http/Controllers/Webhooks/TelegramWebhookController.php

Cambios en .env:
  - TELEGRAM_WEBHOOK_SECRET_TOKEN= (vacío por defecto)

Cambios en config/services.php:
  - Sección 'telegram': agregada
    'webhook_secret_token' => env('TELEGRAM_WEBHOOK_SECRET_TOKEN')

Cambios en TelegramWebhookController.php:
  - El método handle() ahora verifica el header X-Telegram-Bot-Api-Secret-Token
    cuando TELEGRAM_WEBHOOK_SECRET_TOKEN está configurado.
  - Si el secreto está configurado y falta el header o no coincide (hash_equals),
    responde con 401 Unauthorized y loguea la advertencia.
  - Si el secreto NO está configurado, acepta el webhook pero loguea una
    advertencia para que el operador lo configure (estrategia de despliegue
    gradual que no rompe bots existentes).

Cómo usarlo en producción:
  1. Generar secreto: php -r 'echo bin2hex(random_bytes(32));'
  2. Configurar TELEGRAM_WEBHOOK_SECRET_TOKEN en el .env de producción
  3. Configurar el mismo valor en Telegram Bot API (setWebhook con parámetro secret_token)

Verificaciones:
  - php -l: sin errores de sintaxis en los archivos modificados
  - Pruebas: TelegramLinkingTokenTest (2 passed)
